# Wisp releases

Release binaries for **Wisp** by [Small Group](https://smallgrp.com), a self-hosted cloud in a single binary.

Each release has:
- `wisp-linux-amd64`
- `wisp-linux-arm64`
- `checksums.txt` (SHA-256)

Wisp servers check this repository for new versions, and platform admins upgrade from the console or with `wisp upgrade`.

Releases are published automatically by CI. This repository contains no source code.
